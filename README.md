# WhatsApp Channel Reaction — Vercel

Website statis HTML/CSS/JavaScript.

## Deploy ke Vercel
1. Upload folder ini ke repository GitHub.
2. Di Vercel pilih **Add New → Project**, lalu import repository.
3. Framework Preset: **Other**.
4. Build Command: kosongkan.
5. Output Directory: `.` (root proyek).
6. Klik **Deploy**.

Alternatif: dari dashboard Vercel, gunakan fitur upload/deploy project jika tersedia dan unggah isi folder ini.

Catatan: ini hanya frontend. Tombol menyimpan konfigurasi di halaman dan tidak mengirim reaksi WhatsApp. Untuk aksi nyata diperlukan backend yang aman dan integrasi WhatsApp yang mendukung Channel.
